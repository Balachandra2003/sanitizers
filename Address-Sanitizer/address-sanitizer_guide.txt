Address-Sanitizer:
1.AddressSanitizer finds memory-related bugs, such as:
	Buffer overflow (stack/heap)
	Use-after-free
	Use-after-return
	Double free
	Invalid memory access
	In short: anything related to wrong memory access
2. When to use ASan:
	Pointers
	Arrays
	Dynamic memory
	Low-level C/C++ code
Command:
clang++ <filename.cpp> -fsanitize=address -g -O0 -o <any name>
	where:
		-fsanitize:flag
		-g:debug
		-O0:optimizatation level
